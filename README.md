# 🐘 Тапай за Новых! - Реферальная система

## Что реализовано:

### ✅ Задание "Пригласить друга"
- Награда: **10 000 очков** за каждого приглашенного друга
- Уникальная реферальная ссылка для каждого игрока
- Кнопка "Поделиться ссылкой" с интеграцией Telegram WebApp
- Отображение количества приглашенных друзей
- Автоматическое отслеживание кто кого пригласил

### 📁 Измененные файлы:

1. **script.js** - основная логика реферальной системы:
   - `getReferralCode()` - генерация уникального кода
   - `getReferralLink()` - создание ссылки вида `t.me/YourBotUsername?start=ref_ID`
   - `inviteFriend()` - кнопка поделиться через Telegram
   - `checkReferralOnStart()` - обработка входа по реферальной ссылке
   - `completeInviteTask()` - проверка и начисление награды
   - `loadInvitedFriendsFromDB()` - загрузка статистики из базы

2. **supabase-config.js** - SQL скрипт для создания таблиц:
   - Таблица `players` - данные игроков
   - Таблица `referrals` - связь кто кого пригласил
   - Индексы для быстрого поиска
   - RLS политики безопасности


Замените `YourBotUsername` на имя вашего Telegram бота (без @).

### 3. Настройте бота:
В вашем `bot.py` убедитесь, что обработчик start_param настроен:

## 🔧 Как работает:

1. Игрок открывает игру → генерируется уникальный код `ref_<telegram_id>`
2. Игрок нажимает "📤 Поделиться ссылкой" → открывается стандартный шеринг Telegram
3. Друг переходит по ссылке → бот получает `start_param=ref_123456789`
4. Система записывает в базу: `referrer_id → referred_id`
5. Приглашающий нажимает "Получить награду" → проверяется база → начисляется 10 000 очков
